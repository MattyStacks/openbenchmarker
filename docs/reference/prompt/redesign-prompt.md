3. **Buildings are plain boxes.** Build procedural tower archetypes from merged/instanced parts instead of one unit cube: tiered setbacks, podium bases, slab towers, cylindrical/octagonal towers, megastructures with sky bridges between neighbours, plus detail kits (ledges, AC units, pipes, ribs, rooftop antennas/spires/water tanks, billboards frames).
